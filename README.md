# Woovebox Patches Exchange

A static website accessible [here](https://wpe.da-carton.workers.dev/) for sharing instrument patches for the [Woovebox](https://www.woovebox.com/) groovebox. Browse the collection, filter by instrument, style or author, listen to an audio sample, and download the patch as a `.syx` file.

> This is a personal project. It is in no way affiliated with Woovebox or Pocket Animal Audio Pty. Ltd.
